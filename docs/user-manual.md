# 高校社团活动全流程管理系统操作说明书

系统设计报告附录 B · 需求基线 v1.0

## 1. 启动和登录

### 1.1 启动带数据的演示

从项目仓库下载源码并解压，在包含 `requirements.txt` 的目录打开终端。验收复现使用 Python 3.14。

Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --index-url https://pypi.org/simple -r requirements.txt
.\.venv\Scripts\python.exe -m app.demo
```

Linux Bash

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --index-url https://pypi.org/simple -r requirements.txt
.venv/bin/python -m app.demo
```

终端出现启动完成提示后，打开 [本机演示](http://127.0.0.1:8765/)。如果 8765 已被使用，可在启动命令后加 `--port 8767`，再打开 [8767 端口的演示](http://127.0.0.1:8767/)。终端需要在演示期间保持运行，按 `Ctrl+C` 可关闭。

初始数据含 20 个社团、120 场活动、40 个场地和 50 条有效报名。演示数据保存在临时 SQLite 数据库中，每次重新启动会生成一套初始记录。要跨重启保存操作，请使用第 8 节的持久化启动方式。

### 1.2 切换角色

打开演示会进入独立登录页。选择身份后点击「进入工作台」。工作台顶部显示当前角色和账号，点击「切换账号」可回到选择页，点击「退出」可结束会话。同一浏览器刷新时可继续使用有效会话。表中的令牌供本地演示接口调用使用。

| 登录选项 | 演示接口令牌 | 用途 |
|---|---|---|
| 编程社负责人 | `demo-student` | 策划活动和预约场地，也可报名、查学分和评价 |
| 网络技术社负责人 | `demo-network` | 管理本社活动，也可报名参加编程社活动 |
| 校方管理员 | `demo-admin` | 审核、维护场地、处理征用、签到、认定学分及查询统计 |
| 访客浏览 | — | 浏览已通过审核的社团、公开活动、场地与设备 |

## 2. 找到办理入口

| 要办理的事项 | 所用身份 | 页面入口 |
|---|---|---|
| 成立社团 | 学生 | 「社团 → 申请成立社团 → 提交申请」 |
| 提交社团年审 | 社团负责人 | 「社团 → 提交社团年审 → 提交年审」 |
| 保存活动草稿 | 社团负责人 | 「活动 → 活动策划与草稿 → 人工确认并保存草稿」 |
| 申请活动审批 | 社团负责人 | 「活动 → 提交活动审批 → 提交审批」 |
| 申请场地 | 社团负责人 | 「场地 → 申请场地 → 提交场地预约」 |
| 参加活动 | 学生 | 「活动 → 活动报名 → 报名」 |
| 审核和指派 | 管理员 | 「社团」「活动」和「场地」页各有对应审核表单 |

桌面工作台使用左侧菜单。活动页提供常用办理入口，场地申请表位于场地列表上方。窄屏将菜单移到内容上方。

## 3. 提交、审批与验收场地预约

1. 在登录页选择「编程社负责人」，进入工作台，点击「场地」。页面上方可见「申请场地」。
2. 在「已审批活动」选「网页设计入门课」，点击「筛选可用场地」。
3. 在「预约场地」选一间候选教室，如「备用投影教室」，点击「提交场地预约」。看到「场地预约已提交，等待审核」后，可在「预约与征用状态」查到「待审核」。
4. 点击顶部「切换账号」，选择「校方管理员」。在「场地 → 处理场地预约」，选对应活动和场地，选「通过」，点击「处理预约」。
5. 查看「预约与征用状态」中该条预约标为「已通过」，再到「活动 → 公开活动」核对场地名称。

预约沿用活动审批时确定的时间。下拉框列出当前负责人名下已审批、尚未开始且没有有效预约的活动。若「网页设计入门课」之前已经提交过，直接到「预约与征用状态」查看。被退回且尚未开始的活动可以重新申请。候选列表按时段、容量和设备筛选，提交及审批时还会重新检查。

### 申请舞台或报告厅

先在「场地与设备」核对容量和设备名称。为新活动填写对应设备后提交审批，获批即按同一流程预约。设备每行填一项，采用场地列表里的名称。

| 活动 | 可采用的设备填写示例 | 已有样例可从「公开活动」核对 |
|---|---|---|
| 成果展演 | 舞台灯光、舞台音响，分两行填 | 「摄影社 · 成果展演」已预约「舞台 01」 |
| 专题报告 | 讲台、无线麦克风，分两行填 | 「摄影社 · 专题报告」已预约「报告厅 01」 |
| 普通课堂 | 白板 | 「场地与设备」可查各间普通教室 |

## 4. 完整活动流程

### 4.1 社团成立和年审

1. 学生进入「社团 → 申请成立社团」，填写社团名称后提交，在「社团申请与审核状态」查看进度。
2. 管理员进入「社团申请审核」，从「待审核社团」选择记录，选「通过」或「退回」，点击「保存审核结果」。通过的社团进入公开列表，申请人可创建该社团的活动。
3. 负责人办理年审时，在「提交社团年审」选择社团、填写年份和材料，点击「提交年审」。每个社团同一年只可提交一份。
4. 管理员在「查询社团年审」选社团并点击「查看年审」，随后在「处理年审」选择待审核记录，保存结果。负责人可在同一查询区查看结果。

### 4.2 活动策划、人工确认和审批

1. 负责人前往「活动 → 活动策划与草稿」，选主办社团，草稿选「新建草稿」。已有草稿或被退回的活动可在该下拉框选择并编辑。
2. 手工填写策划，或先填写「活动构想」并点击「用 DeepSeek 生成草案」。生成所需的服务配置见第 7 节。检查生成结果后，可以修改表单中的任意策划字段。
3. 填写名称、简介、报名上限、计划时长、所需场地容量、活动目标和活动流程。目标、流程、设备和注意事项分别每行一项。点击「人工确认并保存草稿」，在「草稿与审批记录」看到「草稿」。
4. 在「提交活动审批」选该草稿，填写学期、活动类型、未来的开始时间以及更晚的结束时间，再点击「提交审批」。日期按浏览器所在时区录入和显示。
5. 管理员在「活动 → 活动审批」选择待审批活动，选处理结果，可填写 0 至 5 的协调优先级，点击「保存审批结果」。通过后活动出现在「公开活动」。退回后负责人可修改并重新提交。
6. 负责人需要场地时按第 3 节提交预约。管理员审核场地申请后，核对公开活动里的场地。

手填样例可以用「校园海报设计体验课」。报名上限和所需场地容量都填 20，目标填「完成一张招新海报」，流程用两行「示例讲解」「现场练习」，设备填「白板」。若要在同一场验收中演示签到和活动完成，可用几分钟后开始的短时段，按实际时间推进。

### 4.3 报名、签到、完成和学分

1. 选择「网络技术社负责人」充当参与者，在「活动 → 活动报名」选择已发布且尚未开始的活动，点击「报名」，在「我的报名」中确认状态。开始前可选中这场活动再点击「取消报名」。
2. 切换到「校方管理员」。在「学分 → 配置活动学分」选活动、填写学分值并保存。未另设规则时，每名符合条件的学生获 1 学分。
3. 活动开始后，管理员进入「活动 → 报名名单与签到」，选该活动并点击「查看有效报名」。选择待签到学生，点击「登记签到」。核对名单中的签到时间。历史名单仍可查阅，登记签到只在活动时段内开放。
4. 活动结束后，管理员在「确认活动完成」选择该活动，点击「完成活动并认定学分」。系统只为有效报名且已签到的参与者认定学分，同一活动不会重复认定。
5. 切回参与者账号，进入「学分 → 我的学分」，点击「查询学分」。学期留空可查全部。核对来源活动、学期、学分和认定时间。

现场演示到达时段边界后，可刷新页面再查询。初始样例中，「编程社负责人」可以直接查到「Python 入门工作坊」的 1 学分。

### 4.4 评价与统计

1. 已签到的参与者在活动被确认完成后，进入「评价 → 提交活动评价」，选活动、填 1 至 5 分，可补文字评价，再点击「提交评价」。已评价的活动会移出待评价列表。
2. 管理员在「评价 → 查阅活动评价」选已完成活动，点击「查看评价」，查看平均分和评价明细。初始样例「Python 入门工作坊」已有一条评价，可直接查阅。
3. 管理员在「统计 → 活动与参与统计」点击「查询统计」。学期留空查看全部，填写时使用活动提交时的学期名称。页面显示活动数、有效报名人次、签到人次、去重报名学生数、已认定学分，并按学期、社团和活动类型列出明细。在未新增业务记录的样例库中，可核对活动 120、有效报名人次 50、签到人次 1、已认定学分 1。

## 5. 演示临时征用与批量换场

### 使用已准备好的案例

1. 选择「校方管理员」登录，从「场地」点击上方的「换场协调」。
2. 在「征用记录」选「校级考试临时征用」，点击「查看候选与建议」。
3. 核对两条建议以及原定开始时间。「校园编程分享会」可使用「备用投影教室」，「网络实验体验课」需要网络，建议使用「投影网络教室」。
4. 保留建议或从各行的下拉框中选择替代场地，点击「人工确认所选场地」。页面应提示确认 2 条安排。回到「预约与征用状态」和「公开活动」核对新场地，原时段保持一致。
5. 同一征用处理完后再次打开，会显示「没有待协调的预约」。要从头演示，可以开启新的一次样例演示。若某活动没有可用场地，保留它待协调，管理员后续处理。

### 自行设置征用与维护场地

- 「场地 → 维护场地」可新建或编辑场地。填写名称、容量及逐行填写的设备，点击「保存场地」。调整已有场地时，原定预约仍须满足活动条件。
- 「场地 → 学校临时征用」可选一个或多个场地，填写起止时间和征用原因，点击「登记征用」。页面自动列出受影响预约，再按上一节确认。
- 需要复现冲突时，可用两个未来同一时段、设备要求相容的已审批活动，依次申请同一间教室。第一条提交后会暂时锁定时段，第二条会被拦截。可改选其他可用场地或由管理员退回第一笔申请。

## 6. 常见问题

| 现象 | 处理方法 |
|---|---|
| 页面只有公开列表 | 从顶部点「登录」，演示版选择学生或管理员，再按对应角色找表单。 |
| 申请场地没有可选活动 | 查活动是否已审批、是否属于当前账号负责的社团、是否尚未开始，以及是否已有预约。 |
| 筛不到舞台或报告厅 | 核对设备文字与场地列表一致，并查看时间占用、征用及场地容量。 |
| 找不到已结束活动的签到按钮 | 用「查看有效报名」查历史名单。登记签到在活动进行期间开放。 |
| 找不到刚结束的活动或没有待评价项 | 更新当前页面的状态。完成动作由管理员在结束后执行，评价由已签到且尚未评价的参与者提交。 |
| 学分为空 | 确认同一学生的有效报名和签到已存在，管理员已经完成活动，学期筛选与活动一致。 |
| 端口打不开 | 看终端是否启动完成和仍在运行，浏览地址使用终端显示的端口。 |
| 安装或启动提示找不到模块 | 核对安装依赖和启动使用的是同一个虚拟环境。若 Ubuntu 提示缺少 `ensurepip`，先安装与系统 Python 版本匹配的 `venv` 支持组件。 |

## 7. 在演示中启用 DeepSeek

可用以下构想尝试生成草案。

> 组织一次面向 20 名学生的校园海报设计活动，时长 60 分钟，场地需要白板。安排示例讲解、小组练习和展示。

运行服务前，在同一终端设置服务端环境变量 `DEEPSEEK_API_KEY`。Windows PowerShell 可用以下方式输入自己的密钥。

```powershell
$deepSeekSecret = Read-Host 'DeepSeek API Key' -AsSecureString
$env:DEEPSEEK_API_KEY = [System.Net.NetworkCredential]::new('', $deepSeekSecret).Password
.\.venv\Scripts\python.exe -m app.demo
```

Linux Bash 可用以下方式。

```bash
read -r -s -p 'DeepSeek API Key: ' DEEPSEEK_API_KEY
printf '\n'
export DEEPSEEK_API_KEY
.venv/bin/python -m app.demo
```

生成后的草案留在表单中，负责人点击「人工确认并保存草稿」后才写入数据库。在线调用可能计费。若提示未配置密钥，核对服务启动前的环境变量。若提示调用失败或超时，检查网络和账户配置，或手填策划继续。

## 8. 持久化、数据库交接与验收

从项目目录按 [README 本地启动](../README.md#本地启动)配置学生、管理员及可选的其他学生账号。Windows 运行 `.\.venv\Scripts\python.exe -m uvicorn app.main:app`，Linux 运行 `.venv/bin/python -m uvicorn app.main:app`。浏览器打开 [普通模式](http://127.0.0.1:8000/)。数据库默认为项目当前运行目录下的 `campus.db`，首次普通启动从空库开始。

需要迁移已办理的数据时，先关闭写入该库的服务，再复制 `campus.db`。接收方放入项目运行目录，或通过 `DATABASE_URL` 指向备份的 SQLite 文件。使用已有社团和报名记录时，需要保留原额外学生账号的 ID，可为这些 ID 配置新令牌。样例演示的临时数据库和普通模式各自独立。

课程验收可依次检查「提交场地申请并审批」「临时征用后确认双活动换场」「新建活动到认定学分」三条操作链。接口材料与测试结果见仓库中的 [需求追溯矩阵](traceability.md)、[验收记录](acceptance.md)和[系统设计报告](design-report.md)。完整报告交付时，将本说明书与本地保留的两张 TRAE 原图一起附上。
